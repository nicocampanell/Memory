# c4-proof: the number people screenshot (12 beats)

Technique: land the payoff on the drop.

```text
Make scenes/c4-proof/clip.mp4: a 12-beat payoff moment for Abode Money, the product in kit/. Follow CLAUDE.md and LOOK.md, and use the tempo in kit/AUDIO.md.

Beat 0: the payoff number from kit/BRAND.md, exactly as the product formats it, rises in huge in the centre, about 220px.
Beats 2, 4, 6 and 8: the real rows that make up that number land one by one under it. Each gets a check on its beat, and the big number moves by exactly that row's real amount, with a coin sound. It lands on the final value on beat 8, with the impact sound.
Beats 9-12: the number slides up and the payoff line rises in under it, with one serif accent word.

Check the arithmetic against the real rows before animating: the rows must add up to the total. The counter must never show a value that isn't on the way from start to end, never a negative zero, and never two values blurred on top of each other (drive it from M.frameT). Start the song at whatever offset puts the drop on beat 8.
```
