# film: one timeline, the drop on the payoff

```text
Make scenes/film/film.mp4: one continuous launch film for Abode Money, built from scenes/c1-hook, c2-demo, c3-morph, c4-proof and c5-end. Follow CLAUDE.md and LOOK.md.

Order: hook, demo, morph, proof, end card.
- Put all five on one timeline in one index.html, with one clock and one soundtrack. Reuse each scene's code instead of redrawing it.
- Each scene hands over to the next through a shared shape: a dot, a pill, a card or a number grows into the next scene. Never a cut, never a fade. Design those handoffs yourself.
- Line the song up so its drop lands on the payoff moment in the proof scene. Start the song at whatever offset that needs. Trim scenes by whole beats if you must, never stretch time.
- Everything must read on a phone: any card in focus fills at least half the frame width, and on-screen text is never smaller than 28px.
- Keep every effect on its event and let the renderer normalise to -14 LUFS.

Show me the full beat map with the drop marked, then render. Run every check in CLAUDE.md.
```

## Notes round (after you watch it)

Write each note as the problem plus the result you want, not the fix:

```text
Notes from Abode after watching film.mp4:
1. "<time>: <problem>. <result we want>."
2. ...
3. ...
Change only what these notes need. Keep the timing, the sound and everything else. Check the frames at those moments before and after, re-render, and tell me in three lines what you changed.
```

Read every clip's "what I'd still change" list first. Half your notes are already written.
